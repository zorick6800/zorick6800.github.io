Cloud ETL

Building a financial data lake with AWS Glue and PySpark

I brought financial records from Netezza and RDS into a partitioned S3 data lake so analysts could query curated tables in Athena and Redshift.

S3 · AWS Glue · PySpark · Lambda · Step Functions · Redshift
Technical walkthrough

EventBridge triggered Python extracts into the raw layer. Glue jobs deduplicated records, cast fields to consistent types, and wrote Snappy-compressed Parquet. Step Functions ran the JSON reference-data conversion alongside those jobs and handled retries.

Before publication, a Lambda function checked row counts, null thresholds, schema, and freshness. A failed check stopped the load and sent an SNS alert.
